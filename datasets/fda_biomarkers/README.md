# FDA Biomarker Table — Datasets

This folder contains all data artifacts and processing scripts generated from the FDA Biomarker Table extraction pipeline.

## Folder Structure

```
datasets/
├── raw/          ← Original source files (PDF + Markdown extraction)
├── processed/    ← Intermediate and individual JSON files per biomarker
├── benchmark/    ← Final JSONL dataset for chunking experiments
└── src/          ← Processing scripts
```

### `raw/`

Original source files, unmodified:

- `Biomarker Table with Text 01-06 2024 FINAL (1).pdf` — FDA biomarker table PDF downloaded from [fda.gov](https://www.fda.gov/media/124784/download?attachment)
- `datalab-output-*.pdf.md` — Markdown extraction generated by the [Datalab API](https://www.datalab.to/app/playground/documents/new)

### `processed/`

Intermediate outputs from the processing pipeline:

- `output.json` — Initial structured JSON converted from Markdown (Step 2)
- `final_output.json` — Clean, reorganized JSON after fixing page-break artifacts (Step 3)
- `*.json` (597 files) — Individual JSON file per drug–biomarker pair (Step 4)

### `benchmark/`

Final dataset ready for RAG and chunking experiments:

- `fda_biomarkers.jsonl` — All 597 biomarker records in JSONL format, one record per line, with `content`, `source`, `url`, and `version` fields

### `src/`

Python scripts that reproduce the full pipeline:

| Script | Step | Description |
|--------|------|-------------|
| `transform_to_json.py` | 2 | Converts Markdown table → `output.json` |
| `reorganize_content.py` | 3 | Fixes page-break overlaps → `final_output.json` |
| `json_split_and_clean_fda_biomarkers.py` | 4 | Splits into individual JSON files |
| `combine_json_to_jsonl_fda_biomarkers.py` | 5 | Combines individual JSONs → `fda_biomarkers.jsonl` |

## How to Reproduce

### Prerequisites

Download the FDA biomarker table PDF from:
```
https://www.fda.gov/media/124784/download?attachment
```

Then process it with the [Datalab API](https://www.datalab.to/app/playground/documents/new) to generate the Markdown extraction file.

### Run the Pipeline

From the `src/` directory, run each script in order:

**Step 2 — Markdown to JSON:**
```bash
python transform_to_json.py
```
> Update the `md_file` variable in `main()` if your Markdown filename differs from the default.

**Step 3 — Reorganize content:**
```bash
python reorganize_content.py
```

**Step 4 — Split into individual files:**
```bash
python json_split_and_clean_fda_biomarkers.py
```

**Step 5 — Combine to JSONL:**
```bash
python combine_json_to_jsonl_fda_biomarkers.py
```

### Script Configuration

- **`transform_to_json.py`**: Update `md_file` in `main()` if your Markdown file has a different name.
- **`reorganize_content.py`**: Input/output filenames are hardcoded (`output.json` → `final_output.json`). Modify `main()` to change them.
- **`json_split_and_clean_fda_biomarkers.py`**: Defaults to `final_output.json` as input and `processed_json/` as output directory. Both can be overridden via command-line arguments.
- **`combine_json_to_jsonl_fda_biomarkers.py`**: Defaults to `processed_json/` as input and `fda_biomarkers.jsonl` as output. Both can be overridden via command-line arguments.
