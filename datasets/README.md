
## Datasets

This repository uses benchmark-oriented datasets designed for studying
retrieval behavior in Retrieval-Augmented Generation (RAG) systems.

Current corpora include biomedical and FDA-related documents processed
into structured JSONL collections suitable for:

* chunking experiments
* dense retrieval evaluation
* embedding benchmarking
* Recall@K analysis
* downstream RAG pipelines

Datasets are separated into raw, processed, and benchmark-ready
artifacts to ensure reproducibility and modular experimentation.
